# Student Academic Management and Result Processing System

## Project Description

This is a console-based Programming Fundamentals project developed in C.

The system is designed to manage student academic information in one place. It will include student registration, course registration and allocation, marks, attendance, fee records, teacher feedback, grades, GPA and academic status.

## Main Features

- Student Registration and Profile Management
- Search, Update and Delete Student Records
- Course Registration
- Course Allocation
- Marks and Result Management
- Attendance Management
- Fee Submission and Fee Status
- Teacher Feedback
- Grade and GPA Calculation
- Academic Status
- File Handling for Storing Records

## Tools and Technologies

- Programming Language: C
- IDE: Visual Studio Code
- Operating System: Windows
- Version Control: GitHub
- Application Type: Console-based
